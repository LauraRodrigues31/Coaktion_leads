# TotemLeads — Documentação da Proposta

Site de documentação (Docusaurus) com a proposta de projeto do sistema de
captação de leads offline para totens de evento.

## Rodando localmente

```bash
npm install
npm start
```

Abre um servidor de desenvolvimento local em `http://localhost:3000` com
hot reload.

## Build

```bash
npm run build
```

Gera os arquivos estáticos na pasta `build/`.
